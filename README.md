# IceNote 📝

> **IceNote v1.0 is officially released!** 🎉 
> A minimalist, fast, and local-first note-taking application inspired by the simplicity of Google Keep and the privacy-focused philosophy of Obsidian.

---

## 🌐 Live Demo
Try the application directly in your browser without any installation:
👉 **[Open IceNote on GitHub Pages](https://theteaone.github.io/Icenote/)**

---

## 💡 Project Philosophy
The main goal is to create a fast and intuitive tool where notes belong solely to the user. All data is stored locally on your device, ensuring maximum confidentiality (**Local-first**). No clouds, no tracking, no third-party servers.

---

## 🚀 Current Features
* **Full Privacy**: Your data never leaves your browser (powered by `localStorage`).
* **Markdown Support**: Fast and flexible text formatting using Markdown syntax.
* **Media Support**: Attach images directly to your notes.
* **Organization & Workflow**:
  * **Pin Notes**: Keep critical notes at the top.
  * **Archive & Trash**: Safely store or delete notes with instant restoration.
  * **Instant Search**: Real-time filtering by title and content.
* **Theme Switching**: Seamless toggle between Dark and Light visual modes.
  * **Mobile-Responsive UI**: Responsive layout for mobile devices with a slide-out drawer navigation menu and overlay.
* **Layout Toggle**: Switch dynamically between Grid and List views.

 ## 🛠 Tech Stack
- **HTML5 / CSS3**: Advanced layouts with Grid, Flexbox, Media Queries, and CSS Variables.
- **Vanilla JavaScript (ES6+)**: DOM API, Event Delegation, propagation control, and `localStorage` management.
- **Marked.js**: Fast client-side Markdown rendering.
- **SVG Graphics**: Lightweight, inline icons for instant rendering.
